Rogue 3.4 JEC ― Windows版
==========================

Rogue 3.4 JECは、1981年のBerkeley版Rogue 3.4を再構成した
ソースコードをもとに、日本語化および現代のWindows向けの対応を
加えたものです。1981年当時のオリジナルソースそのものではありません。
ゲームルールは基本的に3.4に準拠しています。

【ZIPに含まれるファイル】
  rogue34.exe           通常版（起動時の表示言語はOS設定による）
  README_ja.txt         この説明書
  README_en.txt         英語版説明書
  rogue_ja.txt          日本語版案内書（テキスト）
  rogue_ja.html         日本語版案内書（HTML）
  rogue_en.txt          英語版案内書（テキスト）
  rogue_en.html         英語版案内書（HTML）
  LICENSE.txt           著作権・ライセンス情報

【起動方法】
Windows 64ビット環境で、rogue34.exe をダブルクリックして起動します。
Windows TerminalおよびConsoleHostでの動作を想定しています。
ゲーム画面は80列×24行で、ダブルクリックによる起動時には必要に
応じて端末サイズを調整します。既存のターミナルから起動した
場合は、端末ウィンドウのサイズを強制変更しません。
日本語・絵文字の表示には、対応する端末およびフォントが必要です。

標準のセーブファイルがない場合は新しい冒険を開始します。
セーブファイルがある場合のダブルクリック起動では、
  RまたはEnter : セーブした冒険を再開
  N             : 新しい冒険を開始
  F             : ファイルを選んで再開
  Q             : 終了
のメニューが表示されます。

【主な操作】
  h / j / k / l    左／下／上／右へ移動
  y / u / b / n    斜めに移動
  i                持ち物を表示
  o                オプション画面（表示言語の変更にも対応）
  ?                コマンドヘルプ
  S                セーブして終了
  Q                ゲームを終了
  !                一時的にシェルを開く（exitで戻る）

【セーブ・スコア】
実行ファイルは次の既定ファイル名を使用します。
  rogue34.save      セーブファイル
  rogue34.scr       スコアファイル
保存先はプログラムの「実行時のカレントディレクトリ」です。
必ずしもEXEのあるフォルダと一致するとは限りません。
セーブ形式はR34SAV02です。

既存のターミナルから起動する場合は、次の指定ができます。
  rogue34.exe -r              標準セーブファイルから再開
  rogue34.exe -s              スコアを表示
  rogue34.exe "保存名.save"    指定したファイルから再開

表示言語はROGUEOPTSの language=ja / language=en でも指定できます。
ROGUE_LANGは使用しません。終了したゲームのスコア表示は、
ダブルクリック起動時だけリターンキーの入力を待ちます。
